# Manos Corp trials

Two Manos Corp full-stack trial submissions, same repo, one folder each:

- [`trial-1-youtube-metadata/`](trial-1-youtube-metadata/) — YouTube metadata fetcher
  (Python + yt-dlp, FastAPI, Next.js). See its own [README](trial-1-youtube-metadata/README.md).
- [`trial-2-video-generator/`](trial-2-video-generator/) — automated topic-to-mp4 video
  generator. See its [README](trial-2-video-generator/README.md).

Each folder is self-contained: its own dependencies, its own `.env`, its own instructions.
